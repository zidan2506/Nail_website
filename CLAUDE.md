# Claude Guidelines

## Karpathy Guidelines

Invoke `andrej-karpathy-skills:karpathy-guidelines` at the start of every coding task and strictly follow all 4 principles:

1. **Think Before Coding** — Ask if anything is unclear. Never assume.
2. **Simplicity First** — Only implement exactly what was asked.
3. **Surgical Changes** — Touch only what is necessary.
4. **Goal-Driven Execution** — State a verifiable plan before multi-step tasks.
